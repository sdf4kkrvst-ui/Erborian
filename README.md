# Резервная копия Claude — 29.10.2026

Копия всего, что хранилось в аккаунте Claude и пропало бы при бане. То, что лежит на компьютере, сюда не входит: оно и так у тебя.

| Папка | Что внутри |
|---|---|
| `memory/` | Вся память Claude о тебе и работе: ДНС, ОБИ, водители, тарифы, Эстима, сборка, игра, машина и т.д. Файл `00_ПАМЯТЬ_CLAUDE_полностью.md` можно целиком дать новому Claude |
| `chats/` | Все 72 чата (31.07–29.10.2026): ссылки и подробные пересказы. `00_ВСЕ_ЧАТЫ.md` и таблица `.csv` |
| `artifacts/` | Все 19 артефактов: книги (Markdown), Библии, игра «Тихий Брод 2» (128 файлов), сайты, табель 1509, дашборд, карусели «Бери Живи», документы НЕОКЕМ. Список — `00_СПИСОК.txt` |
| `scheduled_tasks/` | 24 запланированные задачи с полными промптами. 6 повторяющихся — отдельными файлами `recurring_*.md`, по ним задачи легко пересоздать |
| `code/` | Памятка: какие программы из Cowork и Claude Code лежат на ПК и что скопировать на флешку |

Важно:
- Токен Telegram-бота (автопостинг allbegoods) из копии **вырезан**. Если пересоздавать задачу, впиши токен заново.
- Расписания задач «Недостающие реестры», «Отчеты ДНС» и старой проверки записаны в UTC: 08:00 UTC = 11:00 МСК.
- Книги и материалы Эрбориана — в ветке `main` этого же репозитория.
- Полный официальный экспорт чатов можно получить в Claude на сайте или в приложении для компьютера: Настройки → Конфиденциальность → Экспорт данных. Ссылка придёт на почту и действует 24 часа.
