Отчёт ДНС — правила по Пушкино-реестру
- [stated] в реестре Пушкино в колонке «Экспедитор» могут стоять названия маршрутов «Пушкино» и «Софьино» вместо имени водителя — добавлять их в отчёт как отдельные столбцы-водителей с точно такими же названиями («Пушкино», «Софьино»)
- [stated] минималка каждого маршрута (день × курьер) в DNS-реестре по стороне Зуськовой — не менее 22 500 ₽; если дневная сумма тарифов < 22 500 — ставить 22 500

Расчёт реестра для ДНС и ЗП водителям
- [stated] считает их сам в своём локальном приложении «Реестр доставок» (server.py + index.html на рабочем столе), там же геокодирование адресов и определение зоны доставки
- [stated] реестр для ДНС считается по тарифам Зуськовой + НДС 22%; ЗП водителям — по тарифам ПЭК с минимумом 20 600 ₽ за маршрут
- [stated] реестры для ДНС делает Ксения: два реестра — один с маршрутами выше минималки, второй с минималками; для недостающих маршрутов — так же, по тарифам Зуськовой
- [stated] зоны доставки: Внутри МКАД / Мкад-107 / 107-108 / 108 до границ МО; категория заказа определяется по весу и объёму (мелкие, средние, мгт, кгт, средние кгт, крупные кгт)
- [stated] если водитель ездил вместо другого, файл реестра переименовывать по тому, кто реально ездил (без приписки «за …»), чтобы не путаться при выдаче ЗП
